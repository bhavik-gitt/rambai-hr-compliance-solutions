## 🏢 About

**RAMBAI HR & COMPLIANCE SOLUTIONS** is an HR consultancy and labour law compliance service provider based in Ahmedabad, Gujarat, India. The firm helps businesses manage human resources, payroll operations, statutory obligations and workforce compliance.

This repository contains the source code for the RAMBAI website — a premium, modern digital presence where business owners and employers can discover services, understand registration requirements and connect for a consultation.

## 🎯 Core Principles

| Principle | What it means |
|---|---|

| **Compliance** | Helping businesses navigate statutory and labour law requirements. |
| **Progress** | Enabling organisations to operate with greater confidence and efficiency. |

## 🚀 Getting Started

> Commands below assume a standard Node.js project. Adjust them if the project uses a different package manager or tooling.

```bash
# Clone the repository
git clone https://github.com/bhavik-gitt/rambai-hr-compliance-solutions.git
cd rambai-hr-compliance-solutions

# Install dependencies
npm install

# Start the development server
npm run dev

# Create a production build
npm run build
```

## ☁️ Deployment

The site is deployed on [Vercel](https://vercel.com/) at **https://rambai.vercel.app/**. Pushes to the `main` branch can be configured to deploy automatically.
